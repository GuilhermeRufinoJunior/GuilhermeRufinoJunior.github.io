# ATLAS - Professional Website

Executive profile website for Guilherme Rufino Junior, Cybersecurity Consultant.

The project is designed for GitHub Pages publication in the repository `GuilhermeRufinoJunior.github.io`.

## Overview

ATLAS is not a traditional online resume. It is a modern executive profile website for a senior cybersecurity professional, emphasizing trust, strategic experience, threat intelligence, governance and operational resilience.

## Technology

- Semantic HTML5
- Pure CSS3
- Pure JavaScript ES6
- Mobile-first responsive layout
- Complete English and Portuguese language versions with a persistent language selector
- GitHub Pages ready
- Basic SEO, Open Graph, `robots.txt` and `sitemap.xml`

## Local Preview

Open `index.html` directly in a browser or serve the folder with a static server.

## Deployment

1. Copy all files to the root of `GuilhermeRufinoJunior.github.io`.
2. Commit and push to the `main` branch.
3. Enable GitHub Pages if needed using the `main` branch as the source.

## Customization

Update the LinkedIn URL in `index.html` when the final public profile link is available.
